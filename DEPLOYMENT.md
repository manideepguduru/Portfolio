# 🚀 Production Deployment Guide

## Pre-Deployment Checklist

### ✅ Backend (Spring Boot - Render)

**Environment Variables to Set in Render Dashboard:**

1. **Database** (auto-configured via PostgreSQL service)
   - `DB_PASSWORD` — automatically set by Render

2. **CORS** (already set in render.yaml)
   - `CORS_ALLOWED_ORIGINS=https://manideepguduru.com,https://www.manideepguduru.com,https://portfolio-delta-murex-eomyf8lxd8.vercel.app`

3. **JWT** (already set in render.yaml)
   - `JWT_SECRET` — auto-generated by Render (generate if not exists)

4. **Cohere AI Integration** — ⚠️ **MUST SET MANUALLY**
   - `COHERE_API_KEY` — Your Cohere API key (from https://dashboard.cohere.com/keys)
   - `COHERE_MODEL=command-r` (already set)
   - `COHERE_URL=https://api.cohere.com/v2/chat` (already set)

**Steps in Render Dashboard:**
1. Go to https://render.com/dashboard
2. Select **portfolio-backend** service
3. Click **Environment** tab
4. Add/Update: `COHERE_API_KEY=<your-key>`
5. Save and trigger redeploy

## ⚠️ Troubleshooting

### CORS Errors on Production
**Issue:** `Access to XMLHttpRequest at 'https://...' blocked by CORS`

**Check:**
1. Is `CORS_ALLOWED_ORIGINS` in Render correct? 
   - Should include your Vercel domain
2. Did you commit & push `.env.production`?
3. Is the Render backend redeployed? (check deployment logs)

**Fix:**
```bash
# Force redeployment on Render
# Go to Render Dashboard → portfolio-backend → Manual Deploy
```

### Resume Analysis Returns Fallback Score
**Issue:** All analyses return score 88, generic assessment

**Cause:** `COHERE_API_KEY` not set in Render

**Fix:**
1. Get API key from https://dashboard.cohere.com/keys
2. Add to Render dashboard: `COHERE_API_KEY=<key>`
3. Trigger redeploy
4. Try again

### 500 Error on `/api/checker/analyze`
**Issue:** `POST /api/checker/analyze` returns 500

**Check Render Logs:**
```bash
# Via Render Dashboard:
# portfolio-backend → Logs tab
# Search for "error" or "exception"
```

**Common causes:**
- File upload not multipart
- Resume file > 10MB
- Missing COHERE_API_KEY (logs will show connection error)
